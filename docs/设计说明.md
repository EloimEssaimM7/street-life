# 《烟火人间 · 一条老街的十二时辰》设计说明

> 武汉大学 2026「零杯」网页设计大赛 · 主题一「市井烟火 · 百味人间」

## 一、立意

题目里的「烟火」有两层：一层是灶上的白汽，一层是人来人往的热闹。我们想做的不是一条供人观看的老街，而是一条**可以走进去、并且会自己过日子**的街。

所以整件作品不设「开始游戏」「关卡」「进度」。推门进去就是早上七点，天光、灯笼、摊子、行人都按自己的钟点走；你不操作，它也会从清晨走到黄昏。**时间不是按钮，是自己在走**——这句话既是玩法，也是主题。

## 二、空间与技术

- **三维街景**：three.js 0.160（本地化引入，含 GLTFLoader / DRACOLoader / BufferGeometryUtils 与 draco 解码器），16 个店铺 / 摊位模型（14 家临街店 + 炸串摊、烧烤车两个推车）+ 橘猫与两种行道树（`models/` 共 19 个 GLB）、树木与街道由曲线路径生成，店铺按街道法线朝向落位，门口有接地阴影。
- **天上那幅画**：两侧与身后各立一整幅王希孟《千里江山图》局部（`PlaneGeometry(470, 156)`，立在 x=±34、y=38、z=−55 与 z=124），三面围合、用 `alphaMap` 往上淡出并随时辰整体染色（`tintSideSky()`）——街是实的，山是画的，中间用雾把两者缝起来。
- **光**：一盏方向光 + 两层半球补光（天光与地面反光）+ 色调映射（ACES，曝光 1.34），四档时辰各有一套天色、雾色、灯笼亮度与窗光；夜里灯笼逐盏点亮，`emissiveIntensity 2.0` + 光晕贴片。
- **声**：3 段按时辰切换的底噪——清晨 05:00–12:00 放《杯中明月》背景乐、12:00–17:30 白日街市、17:30 之后夜市，换段时交叉淡入淡出；雨声与街声由 WebAudio 合成，另有 6 条操作音效；进店时街道声自动压低。
- **程序化的人**：9 个行人——7 个沿街往返、2 个在店门口闲聊；雨天撑伞，没伞的步速 ×1.4 再 ×1.9，见你靠近会让路；另有猫、麻雀与逐帧生成的白汽（只留包子铺、面馆与两辆推车）。

## 三、交互

| 层 | 内容 |
| --- | --- |
| 走 | `W/S` 前后、`A/D` 横挪（不是转头）、鼠标拖动转视角；移动端左下虚拟摇杆、右下转身 |
| 逛 | 点店铺进店，纸片弹窗写营业时间与招牌、主按钮按行当换措辞；8 家（面馆、糕点铺、奶茶店、杂货店、理发店、鲜果铺、卤肉铺、书店）走一张 HTML 手写菜单 / 价目页，其余进内景实拍、多帧灯箱或各自的专用流程 |
| 做 | 点灯笼（可逐盏点亮）、长按撸猫、空格帮摊主翻串、`E` 应一声吆喝、`G` 打更节奏、守蒸笼、砍价（抹零 / 多添一勺 / 街坊价三种结果） |
| 留 | 走一圈会落下一本**手账**：吃了什么、和谁说过话、点过哪盏灯、走过多少米；可落款成一张**离街小票**（印章「来过」），也可拍一张**拍立得**（相纸带日期与里程） |
| 戏 | 点茶馆「沏一壶」触发一段戏：黑屏旁白三段 → 三张内景依次推近、茶客逐句说话 → 回街并切到夜里 |

移动端单独重排：摇杆、顶栏、底部导航三处避让，720 与 390 宽都验过截图。

第一次引导只讲主干；`E` / `G` / 空格 / 长按 / 拖杯子等动作，在走近猫、夜市推车、奶茶店、包子铺或任意摊子时，由画面左上角的一张操作小纸片就地提醒——这些场景提示本身不写 `localStorage`，记住「第一次引导已看过」的只有 `yanhuo.guide.v1` 一个键。

## 四、视觉

一套宣纸/墨/朱砂的纸面语言：纸底 `#f6edda`、墨字 `#241d17`、朱砂 `#b23a2f`；标题用宋体、说明用楷体，印章式色块做「市井」「来过」。三维画面偏冷，纸面 UI 偏暖，冷暖对撞让「走进画里」这件事成立。

## 五、工程

- 全站 **0 条 http(s) 外链**：three.js / addons / draco、模型、图片、音频全部本地化（字体用系统宋体与楷体，不外链），断网可跑。
- 首屏约 10.9 MB、整包实测 39.51 MB；`start.cmd` 起一个零依赖 Node 静态服务器（只监听 `127.0.0.1`），评委双击即开。
- 无构建步骤、无框架，`index.html` + `css/` + `js/` 直接可读。

## 六、已知取舍

- 没有做账号体系：手账按自然日存在浏览器 `localStorage` 里，同一天刷新还在，跨天自动换新本，换设备不带走；另附一个零依赖 Node 静态服务器与到访 / 手账计数接口（见 README 第三节，后台只记条数与类别名，不承担手账恢复）。
- **彩蛋**：手账里「吃了 / 喝了 / 遇见 / 路过 / 拍了 / 搭话」六类各记满一条，浮出「今日已圆满」纸卡（`js/seals.js`，只读手账渲染结果，不改动原有逻辑）。
- 行人、白汽是程序化的：你已经贴到行人身上时，他会停半步、侧过身说一句「您先过。」（十秒内不重复），点他也会回一句方言味的话，但不会一直盯着你看；白汽只负责往上飘。
- 移动端为触屏重排，未做陀螺仪视角。
